# 面板界面检查 — 2026-10-20

本轮保留现有深浅主题、靛蓝强调色与工作布局，改善控件名称、焦点管理、反馈和可读性，
没有替换视觉设计。对应实现为 [`panel.py`](../porter/panel.py)、
[`panel.js`](../porter/static/js/panel.js)、[`app.css`](../porter/static/css/app.css)
和 [`tokens.css`](../porter/static/css/tokens.css)。

## 已做的改动

- **名称与地标：** 导航具备名称和当前页状态，平板图标栏隐藏文字后链接仍有可访问名称。
  表单 label 正确关联控件，分组切换具备名称，跳转链接指向主内容。
- **记忆抽屉：** 关闭时 dialog 为 inert，并从可访问树隐藏。打开后启用 dialog、移入焦点，
  让外围 shell inert 并锁定背景滚动。Tab/Shift+Tab 在可操作控件间循环，Escape 关闭，
  并在原触发控件仍存在时归还焦点。
- **手机导航：** 菜单按钮公开展开状态和控制目标；窄屏关闭侧栏时 inert 并隐藏。
  断点变化重置状态，Escape 关闭已展开菜单并将焦点还给开关。
- **手机控件：** 图标/复制按钮最小点击区为 44 × 44 CSS 像素；按钮、分段切换和导航高度
  至少 44 像素。手机输入框、文本域和选择框使用 16 像素文字。
- **失败和复制：** HTTP/HTMX 响应错误、网络错误、超时显示本地化反馈；语言切换拒绝失败响应。
  复制包含回退方案，失败时提示并恢复原焦点；toast 区域使用 polite 播报。
- **对比度 token：** 浅色次要文字为 `#626973`，深色为 `#8B94A1`。
  操作按钮的填充/文字与成功、警告、错误等语义文字 token 分开，避免修正一种状态时破坏另一种。
  源码测试按透明度合成和所检查的 hover 状态计算，要求覆盖的普通文字/背景、徽标和按钮组合
  至少达到 4.5:1；它不代表页面所有视觉组合都已实测。
- **动态与画布：** reduced-motion 偏好会关闭抽屉/侧栏过渡和 toast 进入动画。
  每个 canvas 的点击、resize 事件只绑定一次；resize 计算使用 150 ms 防抖。

## 证据与边界

本轮 [`tests/test_panel_accessibility.py`](../tests/test_panel_accessibility.py)
**42 项通过**。检查真实中英文 HTTP 响应中的名称、ID、label/ARIA 引用、地标、抽屉初始状态，
并从发布 CSS 计算对比度。它们不会执行浏览器 JavaScript，不测量实际布局，
不能证明触摸交互或焦点行为正确。

Impeccable 源码检测器运行一次，唯一 warning 是 `.toast` 原有的 3 像素语义色左边框
（检测时位于 `app.css:422`）。它用于区分 success/error/info 状态，因此作为既有反馈结构保留，
本轮没有新增装饰性卡片样式。检测器属于源码启发式检查，不是真实浏览器可访问性审计。

尝试连接浏览器返回 **“No browser is available.”**，未获得截图或浏览器交互结果。
这些修复与测试**不是 WCAG 认证，也不代表视觉验收完成**。
[ACCEPTANCE.zh-CN.md](ACCEPTANCE.zh-CN.md) 中的浏览器门槛继续保留待完成状态。

## 仍需人工检查

使用合成记录，在桌面宽度、**768 px** 和 **390 px** 下检查**中英文、深浅主题**。
记录实际浏览器、视口和候选 commit；截图可选，避免包含密钥。

- 从跳转链接开始用 Tab 遍历；打开记忆抽屉，检查 Tab/Shift+Tab 焦点限制、Escape、
  滚动锁定和关闭后的焦点恢复。
- 768 px 下确认图标栏导航仍可理解；390 px 下打开/关闭侧栏、测试 Escape，
  再调整到桌面宽度。隐藏控件不能收到焦点。
- 审核待确认的合成记忆、搜索/筛选、切换语言/主题，确认正常和 200% 缩放下重要操作不受阻。
- 在浏览器开发工具中临时让 HTMX 请求失败，或临时离线；确认出现本地化失败反馈，
  不应显示虚假成功。完成后恢复联网。
- 预览交接简报，在正常剪贴板权限和拒绝权限时分别测试复制，再测试下载，检查实际内容。
- 开启 reduced motion，重复调整记忆图谱尺寸，确认过渡遵守偏好，一次点击只发起一次抽屉请求。

失败项记录为可复现 issue。HTTP 200、静态颜色计算和检测器结果都不能替代这些浏览器检查。
